# DFT Finance Tracker

DFT Finance Tracker is a web-based personal finance dashboard that helps users monitor and manage financial activities such as income, expenses, accounts, and transactions.

This project has been Dockerized as part of the Information Systems Agile Project Management with DevOps Week 6 assignment.

---

## Technology Stack

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- Node.js
- npm
- Supabase
- Docker

---

## Main Features

The main functions verified in this project are:

1. User authentication
2. Finance dashboard access
3. Financial transaction management

---

Before running the project, make sure the following software is installed:
